# Femboy Mod

A Minecraft mod for Fabric loader and Minecraft 1.20.4 featuring femboy entities with building, protection, and affection abilities. This mod introduces femboy entities that can interact with the player, build structures, protect the player, and show affection through a cutscene where they lay on the player's chest and bring random items.

## Installation

1. Install Fabric loader for Minecraft 1.20.4.
2. Download the mod jar file.
3. Place the jar file in the `mods` folder of your Minecraft installation.

## Usage

1. Spawn a femboy using the spawn egg.
2. Interact with the femboy to build, protect, and show affection.
3. Trigger the cutscene where the femboy lays on your chest and brings random items.

## Commands

- `/femboy spawn` - Spawn a femboy at your location.
- `/femboy cutscene` - Trigger the cutscene.

## Features

- Femboy entities with custom abilities.
- Cutscene where the femboy lays on the player's chest and brings random items.
- Simple GUI for interaction.

## Building

To build the mod, run `./gradlew build`. The mod jar will be generated in the `build/libs` directory.
